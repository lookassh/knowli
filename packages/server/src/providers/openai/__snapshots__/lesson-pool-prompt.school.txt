Checks by another model: [check.hint_judge] Another model judges every non-empty hint: it must follow from the material, be correct in the language of the instructions and not give away the answer or a required element, even in other words. A rejected hint rejects the exercise: fix the hint (null only if no safe hint exists). Unsupported: use only facts from the material; not correct Polish: fix the wording; gives the content away: hint at the reasoning, not the content; if it cannot be fixed, set it to null. [check.blind_solve] An independent solver sees only the child's view (instruction, stimulus, options, word blocks, word bank; the material only when the subject's checker needs it), never the key; its answer must match the answer or an accepted variant, ignoring letter case, punctuation and contracted forms; pairs, groups and cloze gaps are compared position by position. Make the exercise have exactly one solution. lesson_choice has exactly one correct option; in lesson_cloze exactly one bank word fits each gap: never two gaps whose words could be swapped. [check.open_answer] Two independent solvers answer the open question from the child's view and a grader grades both answers against requiredElements; both must be accepted. If a correct answer lacks elements the question does not demand, make requiredElements match the question (for “any two”, require what every valid choice satisfies and move examples to supplementaryElements) or make the question ask for them; do not drop elements the question genuinely requires. If an answer based on the material is graded wrong, check the model answer and criteria against the material, then make the question more precise or add the mistake to commonErrors. The solvers see the material and the grader checks both answers against it. [check.variants] Another model checks every acceptedAnswers variant; a variant not equivalent to the answer is removed (the exercise stays) and the result notes the removal. A removed variant is gone for the child: never add it again; if the removed wording is a correct answer, make the prompt more specific so only the key fits, or remove_exercise and write a different one. When the independent solver answers with a different wording that the same model judges equivalent to the answer (for example another word order), that wording is added to acceptedAnswers (the exercise stays) and the result notes the addition.
